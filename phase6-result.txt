Phase 6 — Automation / n8n
===========================
Status: PASS

Checked:
  - lib/automation-events.ts emitAutomationEvent() behavior.
  - automation_events table exists (Phase 1) and records events.
  - The no-webhook-configured graceful path (runbook requirement).
  - Live n8n reachability (dev environment).

Found:
  - emitAutomationEvent() is best-effort and NEVER throws:
      * Always records the event in automation_events first.
      * If business.n8n_webhook_url is null/empty, returns immediately
        (no delivery attempt) — this is the required graceful no-webhook path.
      * If a webhook is configured, POSTs the event; on success marks
        delivered_at, on non-2xx or unreachable marks delivery_error.
      * Outer try/catch guarantees even an internal bug cannot break the
        widget chat response.
  - lib/automation-events.test.ts (6 tests, all passing) explicitly covers:
      * records event even with no webhook
      * does NOT call fetch when no webhook URL configured
      * POSTs + marks delivered on success
      * records delivery_error on HTTP 500 (no throw)
      * records delivery_error on unreachable webhook (no throw)
      * never throws even when the insert itself fails
  - Live n8n is not reachable in this dev environment (404 / unable to
    connect). This is expected and is exactly the failure mode the graceful
    degradation path is designed for — delivery_error is recorded and the
    widget flow is unaffected.

Fixed:
  - None needed; the graceful no-webhook path is implemented and tested.
